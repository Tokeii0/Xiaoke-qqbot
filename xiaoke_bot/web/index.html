阈值

两条独立的开口路径：被点名（不看打扰度——被叫还不出声才失礼），或有价值且不打断别人。改阈值不会重跑推理，保存后对新消息立即生效。

≥ 此值即回复。调低更爱搭话。
没人点名时要多有用才开口。
调高更宽容，吐槽和玩笑不会被误判。
聊到「提示词 → 感兴趣的话题」里的内容时，达到此值就参与讨论。没填兴趣话题则该判断不生效。
越大越敢插话。这是 3 档打扰度的加权位置，不是档位序号：0 = 没人在聊，1 = 气氛轻松，2 = 别人正在认真讨论。只作用于主动开口，被点名时不受限制。

判定说明（问 Jev 的问题）

这几段文字就是发给 Jev 的判断题本身，直接决定机器人什么时候开口。默认写法偏「是不是在叫机器人」，但触发条件不必和机器人有关——你可以改成按话题、按场景触发，例如「有人在聊部署、报错或服务器相关的话题」。留空则用默认写法。

搭配上面的「插话价值阈值」使用。改成话题触发后，机器人就会在相关话题出现时主动参与，而不只是被叫到才说话。

用 {interests} 占位符插入「提示词 → 感兴趣的话题」里填的内容；不写占位符则自动附在末尾。

每行描述一种具体场景，从不打扰排到最打扰。上面的「打扰度上限 (0–2)」就是按这 3 档的加权位置计算的，所以行数必须是 3。
